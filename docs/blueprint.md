# **App Name**: SpendWise

## Core Features:

- Expense Tracking: Manually input income and expenses to track spending habits.
- Spending Categories: Categorize expenses into predefined categories (e.g., food, transportation, entertainment).
- Budget Goal Setting: Set monthly budget goals for each spending category and track progress.
- Visualized Insights: AI tool to provide visual insights (charts and graphs) of spending patterns and budget performance.
- Dashboard Overview: A dashboard displaying key metrics, budget summaries, and recent transactions.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to inspire trust and security in managing finances.
- Background color: Light blue (#E8EAF6), subtly desaturated, complements the primary blue to avoid harsh contrast and maintain a calm visual field.
- Accent color: Purple (#7E57C2), analogous to the primary blue, contrasts by being brighter and slightly more saturated, making key interactive elements stand out.
- Font: 'PT Sans', a humanist sans-serif, will be used throughout for headlines and body text, promoting readability and a modern yet approachable feel.
- Use simple, outlined icons for categories and actions, ensuring clarity and a minimalist aesthetic.
- Employ a clean, card-based layout for dashboard elements and transactions.
- Use subtle animations to indicate successful actions, such as expense tracking or budget updates.
